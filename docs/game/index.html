Dog Breed Game

Can you beat the AI?

Name the breed in each photo. After every answer you’ll see what an image-recognition AI guessed for the same photo. Twenty dogs per round, picked at random for you.

Shuffling the dogs…

Photos: Dog CEO API, mostly from the Stanford Dogs dataset. The AI is a ResNet-50 (torchvision, IMAGENET1K_V2 weights), an image classifier trained on ImageNet, which includes 120 dog breeds; its guesses were computed ahead of time for every photo. Most of these photos come from ImageNet, so the AI may have seen some of them while it was being trained. Easy and Medium use the 30 and 60 highest-ranked AKC breeds of 2025 that have photos (the Cane Corso and a few others have none); Hard uses the AI’s 120 breeds. Scores are saved only in this browser.
